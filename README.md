# Full Stack E-Commerce Application

A full-stack e-commerce web application built using Java,
Spring Boot, MySQL, React.js and REST APIs.

## 🚀 Features

### Backend
- User Registration & Login
- Spring Security Authentication
- Product Management
- Category Management
- Product Search
- Product Filtering
- Pagination & Sorting
- Price Range Filtering
- RESTful APIs
- MySQL Database
- JPA / Hibernate

### Frontend
- React.js
- React Router
- Product Listing
- Product Details
- Category-wise Products
- Login & Registration
- Responsive UI
- Axios API Integration

## 🛠️ Technologies Used

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Spring Security
- MySQL
- REST API
- Maven

### Frontend
- React.js
- JavaScript
- Axios
- React Router
- Bootstrap
